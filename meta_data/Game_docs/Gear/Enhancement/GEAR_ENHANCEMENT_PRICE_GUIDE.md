## ⚔️ 三、戰力（Combat Power）底層計算公式與換算機制

依據遊戲底層 `meta_datas.tres` 的 `settings` 模組，所有屬性轉換為**戰力值（Combat Power）**的標準換算比例為：

$$\text{1 點 傷害 (Damage)} = \mathbf{1.0 \text{ 戰力}}$$
$$\text{3 點 物理/魔法防禦 (Def / Def\_Mag)} = \mathbf{1.0 \text{ 戰力}} \quad (\text{即 } 1 \text{ 點防禦} = 0.333 \text{ 戰力})$$
$$\text{5 點 生命值 (HP)} = \mathbf{1.0 \text{ 戰力}} \quad (\text{即 } 1 \text{ 點生命} = 0.2 \text{ 戰力})$$

$$\text{裝備戰力增量 } \Delta \text{Power} = \text{int}\left( \Delta \text{Damage} + \frac{\Delta \text{Def} + \Delta \text{Def\_Mag}}{3.0} + \frac{\Delta \text{HP}}{5.0} \right)$$

## ❓ 四、核心解答：為什麼盾牌/防具在 +1 ~ +3 戰力沒變，到 +4、+5 才跳動？

### 📌 關鍵原因拆解：
1. **強化成長率階梯差異**：
   - **+1 ➔ +3**：每一級的強化成長率僅為 **`+5%`**（累計分別為 +5%、+10%、+15%）。
   - **+4 ➔ +6**：每一級的強化成長率直接**翻倍跳升至 `+10%`**（累計達到 +25%、+35%）。
2. **防禦力轉戰力的「3:1 稀釋」與「整數截斷 (Integer Truncation)」**：
   - 強化只提升裝備基礎面板，且**防禦力需要除以 3.0 才能換算成 1 點戰力**。
   - 對於中低階盾牌或防具小件，`+1 ~ +3` 每次提升 5% 換算下來可能只有 **`+0.4 ~ +0.8` 點戰力**，系統介面取整數 (`int`) 顯示時，**小數點直接被捨去，顯示為 `+0`（戰力完全沒變）**！
   - 當升到 **`+4`** 時，累計加成一口氣暴增到 **`+25%`**（單級大漲 +10%），突破了整數門檻，**戰力才會突然向上跳動**！

## 💡 六、各階段強化資源分配策略 (衝 2800 戰力實戰建議)

1. **前期~中期 (Lv.1~60 / 衝 2800 戰力階段)**：
   * **主 C 武器（如冰霜食屍鬼之弓）**：直接強化到 **`+5 ~ +7`**（武器 1:1 轉戰力，單件就能貢獻 +15~+26 戰力，效益最高）。
   * **前排坦克胸甲（如冰霜守衛重鎧）與盾牌**：強化到 **`+5`**（防禦係數高達 0.8~1.0，+5 能提供 +8~+9 戰力並大幅增加坦度）。
   * **防具 4 件套（頭/手/腳/腰）**：全套維持 **`+3`**（小幅補足防禦與過渡戰力）。
   * **暗影青蛙遺物戒 / 飾品**：固定停在 **`+3`**（因為戒指雙防權重只有 0.1，升再高也只加 1~2 點戰力，留資源換 5星競技場戒）。
2. **大後期畢業 (Lv.70+ / 6星彩虹神裝成型)**：
   * 終極畢業武器（如摩西深淵弓 / 莉莉絲之弓）：強化至 **`+7 ~ +8`**。
   * 終極神戒（羅蘭魔像之戒 / 深淵巨獸之戒）：可補至 **`+5`**。

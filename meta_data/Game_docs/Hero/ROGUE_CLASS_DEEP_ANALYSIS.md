## 一、 刺客職業天生基礎與裝備特徵

在底層 `classes.rogue` 定義中：
- **基礎專精屬性**：
  - **閃避率 (`dodge`)**：$+10.0\%$（全職業最高初始閃避）
  - **先攻權 (`first_strike`)**：$+1.0$（開局先手出手優先級）
  - **物理傷害加深 (`physical_con`)**：$+10.0\%$
- **每級屬性成長 (`upgrade_attr`)**：
  - 最小傷害 $+1.0$ / 最大傷害 $+1.0$
  - 物理防禦 $+3.0$ / 魔法防禦 $+3.0$
  - 生命值 $+5.0$
- **裝備規格要求**：
  - 防具：**中甲 (`medium_armor`)**
  - 主手：**匕首 (`dagger`)**
  - 副手：**匕首 (`dagger`)** ⚠️ *(全遊戲唯一副手裝備常規武器的職業)*

## 二、 攻擊對象判定：近戰位移與後排穿透判定

在《黑火遠征》的戰鬥引擎中，攻擊目標判定存在嚴密的底層代碼邏輯：

### 1. 判定參數對比

| 職業 / 典型技能 | 技能目標型態 (`target`) | 近戰攻擊 (`melee_attack`) | 位移要求 (`require_move`) | 實際可攻擊之對象範圍 |
| :--- | :--- | :--- | :--- | :--- |
| **戰士 / 騎士 (常規近戰)** | `melee` (近戰) | `True` | `True` | **僅限敵方最前排目標**。<br>若敵方前排有坦克或雜兵阻擋，嚴禁越過前排打擊後排。 |
| **遊俠 / 法師 (遠程輸出)** | `range` (遠程) | `False` | `False` | **全場任意單體**。<br>原地發射箭矢或法術，可自由選取前排或後排，無阻擋限制。 |
| **刺客核心技能 (背刺/奪命處決)** | **`range` (遠程鎖定)** | **`True` (近戰判定)** | **`True` (必須位移)** | **全場任意單體（特化後排斬首）**。<br>突破前排阻擋限制，物理位移突進至敵方後排，進行近身物理刺殺。 |

### 2. 「近戰鎖遠程」的戰術含義
刺客的核心高階技能（如 `backstab`、`silent_execution`、`deathbound_pressure`、`nightcrow_pierce`、`abyssal_lunge`）在底層配置中呈現特殊的組合：
```json
{
  "target_data": {"party": "enemy", "target": "range"},
  "melee_attack": true,
  "require_move": true
}
```
這意味著刺客**兼具「近戰物理倍率加成」與「遠程無視站位鎖定」**。戰鬥發動時，刺客不受敵方前排坦克的肉身卡位限制，可直接瞬移突進至敵方陣型最深處，精準點殺對方的治療神官、後排法師或脆皮弓箭手。

## 三、 與其他職業之核心本質差異

### 1. 專屬「潛行破隱」增傷機制 (`stealth`)
- 在底層 `buffs.stealth` 中，潛行的定義包含：
  ```json
  {
    "buff_events": ["before_attack", "after_action"],
    "buff_type": "buff",
    "damage_bouns": 0.75
  }
  ```
- **無法選中保護**：進入潛行狀態後，敵方單體技能無法將刺客選為目標。
- **破隱核彈增傷**：當刺客在潛行狀態下發動攻擊時，在傷害結算前自動獲得高達 **$+75\%$ 獨立增傷乘區 (`damage_bouns: 0.75`)**。

### 2. 全遊戲唯一的「雙持匕首」副手機制
- 其他職業副手均為輔助配件（騎士拿盾牌、遊俠拿箭袋、法師牧師拿書本/聖杯）。
- 刺客副手裝備第二把匕首，享有**雙武器稀有詞條堆疊**：
  - 雙倍暴擊率 (`crit`)、雙倍物理傷害加深 (`physical_con`)、雙倍攻擊力數值。
  - 雙武器普攻特效：如兩把匕首均可各自觸發 15% 流血或中毒判定。

### 3. 先攻搶制空權
- 刺客天生自帶 $+1.0$ 先攻權（精靈/夜幕種族進一步疊加至 $+2.0 \sim +3.0$），在對局開啟的第 1 回合擁有極高的先手概率，能在敵方核心後排出手施法前完成先手壓制或擊殺。

## 五、 實戰優勢與致命弱點評估

### 1. 核心實戰優勢 (Strengths)
1. **精準點殺戰術價值高**：
   - 傳統物理隊面對「前排超厚鐵甲戰士 + 後排群體大回血牧師」時往往陷入持久戰；刺客可無視前排阻擋，開場突進後排直接秒殺治療神官。
2. **極致破隱爆發**：
   - 潛行賦予 $+75\%$ 獨立增傷，搭配雙匕首雙倍暴擊詞條，單發暴擊殺傷力極具壓迫感。
3. **高閃避自保與反擊**：
   - 基礎閃避 $+10\%$，結合技能附加的 $3 \sim 5$ 次閃避充能，在面對單體物理打擊時具備高容錯閃避率。
4. **連環擊殺刷新潛力**：
   - 頂級刺客席恩具備 $35\%$ 擊殺/暴擊重置冷卻，在敵方殘血時可單回合連續施放處決大招進行收割。

### 2. 致命實戰弱點 (Weaknesses)
1. **身板極脆，容錯率極低**：
   - 每級生命成長僅 $+5.0$，身穿中甲，沒有戰士/騎士的巨額減傷護盾與重甲防禦；一旦潛行結束或遭遇強控，極易被秒殺。
2. **懼怕強制嘲諷 (`provocation`)**：
   - 當敵方前排坦克（如哥布林機甲格利格、遠古樹靈）發動全體嘲諷時，刺客的鎖定會被強制拉回至坦克身上，完全喪失切後排戰術優勢。
3. **無法規避全體 AoE 魔法打擊**：
   - 潛行的機制為「無法被單體技能選中」，但**無法免疫敵方法師的全體暴風雪或戰士的地震波**。
4. **輸出過度依賴暴擊與前置狀態**：
   - 刺客傷害主要由「潛行增傷 + 暴擊倍率」堆疊而成，一旦面對高暴擊抗性怪物或攻擊未命中，輸出效率會呈現斷崖式下滑。

## 六、 最佳隊伍搭配與協同效應推薦

刺客作為純粹的高風險、高回報近戰突進主 C，必須依賴隊友提供「仇恨轉移、防暴斃保護、易傷鋪墊與容錯復活」：

### 推薦體系 1：【極限保核雙物理秒殺流】
- **前排坦克**：**光輝艾麗娜 (`hero_knight_5`)** 或 **發條機甲·格利格 (`hero_knight_glig`)**
  - **協同機制**：
    - 格利格開場釋放【充壓嘲諷 3 回合】，將全場所有單體仇恨吸附在自身金屬機甲上，確保刺客切入後排時絕不受單體傷害波及。
    - 艾麗娜的【堅韌治療】提供低於 50% 血線時的「強制 5 層護盾急救」，大幅防止刺客突進後的意外暴斃。
- **中排輸出/壓血**：**疾弓芬奇 (`hero_archer_5`)** 或 **精靈塞隆 (`hero_archer_6`)**
  - **協同機制**：
    - 塞隆開場釋放【印記射擊】賦予目標 **5 層印記（$+100\%$ 受到傷害加深）**。
    - 刺客緊接著潛行突進目標，在「$+75\%$ 破隱增傷 $\times 2.0$ 倍印記易傷 $\times$ 暴擊倍率」的乘算下，一回合直接打出超過 **$800\%$** 的核彈秒殺。
- **後排突進主 C**：**影刃·席恩 (`hero_rogue_sien`)** 或 **奪命不死刺客 (`hero_rogue_6`)**
  - **協同機制**：完成後排斬首後，觸發席恩的【鴉羽狩獵】（$35\%$ 刷新全技能），立即轉向敵方輸出位發動第二輪刺殺。

### 推薦體系 2：【高難度地下城容錯體系】
- **核心輔助神官**：**大主教·阿爾德里安 (`hero_priest_aldrian`)**
  - **協同機制**：
    - 刺客身板極脆，高難度 Boss 的 AoE 震盪可能造成刺客意外減員；阿爾德里安具備全遊戲唯一的【使徒復甦】（隊友死亡時原地滿血滿狀態大復活），為刺客體系提供了決定性的容錯保障。
- **輔助戰寵**：**虛銀哨兵 (`pet_voidsilver_sentinel`)**
  - **協同機制**：
    - 戰寵自帶【群體激怒挑釁 3 回合】吸引火力，並為刺客施加【群體防護】（護甲 $+40$ 與保護狀態），使刺客可以在安全環境下打滿多段連擊。

# 雜貨店 (Grocery Store) 系統與兌換圖紙掉落來源速查 🏬

本文件依據遊戲核心資料庫 [`meta_datas.tres`](../../raw_tres/meta_datas.tres) 底層設定，整理城鎮建築「雜貨店」基本機制，以及其販售的 **19 件裝備設計圖** 之獲取來源與掉落性客觀分類。

---

## 一、雜貨店 (Grocery Store) 系統概述

雜貨店為城鎮常駐功能建築，內部包含兩大板塊：

1. **常規物資貨架 (`sell_items`)**：
   - 消耗常規金幣 (`coin`) 購買。
   - 販售品項包含：1~6 階強化石 (`weapon_shard` / `armor_shard` / `charm_shard`)、1~6 階精華 (`essence`)、符文、屬性果實、附魔卷軸。
   - 商店等級共 5 階，每次升級增加 2 格商品位（初始 8 格，最高 18 格），升級費用依序為 400 / 800 / 1,600 / 3,200 / 6,400 金幣。
2. **設計圖兌換處 (`design_drawing_dic`)**：
   - 消耗專屬代幣「圖紙殘卷 / 概念碎片 (`concept_shard`)」兌換。
   - 常駐提供 19 件高品質裝備設計圖（4 件 6 星紅色神話、15 件 5 星橘色傳說）。

> ⚠️ **裝備成品掉落規則**：
> 下述所有 19 件裝備的**「成品裝備」在遊戲全地圖中皆無掉落**。無論設計圖是否可由怪物打出，裝備本體均必須取得圖紙後，在【鐵匠鋪】或【珠寶加工廠】消耗素材鍛造。
